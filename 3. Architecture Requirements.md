# 2. Non-Functional Requirements

**Setup time**:

- How long to setup a new developer on a fresh machine
- Are there instructions in README.MD and are they easy to follow.

**Performance:**

- Cold start under 1 minute.
- All page requests \<1s response time 
- AI-generated content in less than 5 seconds

**Maintainability:**

- **Cyclomatic Complexity:** Measures code branching and structural complexity per function or class.
- **Linting & Code Formatting:** Ensures code formatting, style consistency, and early bug detection..

**Usability**:

- Intuitive UI requiring minimal training.
- Sexyness of the application.

**Security posture**:

- *Check for: *Hardcoded secrets (API keys, credentials), dependency vulnerability counts, input sanitization (SQL injection, XSS prevention), and proper authentication/authorization checks (RBAC)..
