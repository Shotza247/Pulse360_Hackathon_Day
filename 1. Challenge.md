# 1\. Challenge

# 1. Background & Theme

Following the success of our first hackathon (Agentic Orchestration), Hackathon V2 focuses on evaluating **AI-powered App Build IDEs** — platforms that can accelerate full-stack application delivery using AI-assisted development.

Each team will build the **same application** from a common specification using their assigned platform. The use case for this round is an **internal eWay 360° Performance Review application** to be used semi-annually at Ovations Technologies.

**Theme:** AI App Build IDE Challenge  
**Use Case:** eWay 360° Performance Review Application  
**Approach:** MVP 1 (essentials) + MVP 2 (enhancements) + Team Custom Features

# 2. Platforms to be Evaluated

|  | Platform | Status | Category |
| --- | --- | --- | --- |
| 1 | **IBM Bob** | Confirmed | ***Enterprise AI Builder***: An enterprise-grade platform designed for automated, full-stack AI application development and orchestration. |
| 2 | **Atlassian Rovo Dev** | Confirmed | ***Atlassian Ecosystem AI***: An AI-powered assistant natively integrated into the Atlassian stack (Jira, Confluence, Bitbucket) to support software development workflows. |
| 3 | **Anthropic Claude Code** | Confirmed | ***AI Coding Agent***: An autonomous agentic tool powered by Anthropic's Claude, capable of executing complex multi-file coding and terminal tasks directly from the command line |
| 4 | **GitHub Copilot** | Confirmed | ***AI Pair Programmer***: An inline AI assistant that provides contextual code completions, chat assistance, and automated test generation inside popular IDEs. |
| 5 | **OpenAI Codex** | Confirmed | ***AI Code Generation***: OpenAI's dedicated neural network system designed to translate natural language prompts directly into executable code across multiple programming languages. |
| 6 | **Cursor** | Not participating | ***AI-native IDE***: An AI-first code editor (forked from VS Code) built ground-up to feature deep contextual codebase indexing, inline AI editing, and custom model chat. |

# 3. Business Objectives

The hackathon should answer:

1. Which platform produces the **highest quality** application?
2. Does enable **fast delivery**?
3. Provides the **best developer experience**?
4. Is suitable for **enterprise adoption**?
5. Is **cost efficient**?
6. Can teams incorporate **Human-in-the-Loop **during the life cycle  of a feature to check AI-generated output?
7. Can teams **use AI for other Roles **other than simply the Developer role?

# 4. Challenge Format & Rules

- Each team is assigned **one AI platform**
- All teams build from the **same specification** [2. Use Case Specification](https://ovations.atlassian.net/wiki/spaces/Hackathon/pages/1206648836/2.+Use+Case+Specification)

- Teams **must use source control**. 
    - Bitbucket preferred or Github is accepted. 
- **Team must plan **their work into Epics and Stories 
    - Prefer to use **Jira** for work item tracking but can also plan in EXCEL and WORD if not comfortable.
- Teams must demonstrate **Human-in-the-Loop** (HITL) interventions    
(No One-shot or Vibe Coding).
- Teams **may add their own additional features** beyond MVP 1 and MVP 2 **NEW**
- The final solution **must be demo-able locally on a laptop**
- **Technical diagrams / documentation specific to your application **should be generated using your assigned AI platform

6. Evaluation Criteria

| Category | Weight | What Judges Assess |
| --- | --- | --- |
| 1. **Functionality** | **20%** | Could MVP 1 be achieved Any additional features of MVP 2 or additional adds 1% point for every feature. |
| 1. **Code quality** (maintainability, unit tests | 10% | Clean, readable, well-structured code; proper error handling |
